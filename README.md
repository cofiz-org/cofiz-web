# cofiz-web

Marketing site for Cofiz — one shared ledger for Ethiopian coffee businesses. Next.js + Tailwind, DM Sans, primary `#D47311`.

## Product features

Daily coffee prices (Jenfel, Wet, Special), cash distribution to collectors,
purchase logging with receipt photos, cash returns, income & expenses with
Net Balance, automatic debt tracking with repayments, reports with PDF
export, notifications bell with pushes, Telegram/WhatsApp login, offline-first
sync, PIN & idle lock, Admin/Collector/Investor roles, audit log with backup,
Amharic & English UI, in-app updates.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
```

APK buttons link to the latest `cofiz-dist` release. Demo video lives in `public/videos` (WebM + MP4 fallback, WebP poster).
